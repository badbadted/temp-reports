# 行程網頁標準做法

> 新行程一律照這份做。網頁放在 GitHub Pages（https://badbadted.github.io/temp-reports/）。行程由 TED 在電腦上改（第四節）；LINE 群組的小帥只負責留言（第二節）、看圖與綁定。

## 一、開新行程（管理員，30 秒）

在要用的 LINE 群組（小帥要先開著）打：

```
/小帥 新行程 <名稱> <標題>
```

例：`/小帥 新行程 hokkaido-2028 ❄️ 2028 北海道滑雪`

- **名稱**：小寫英文、數字、`-`，會變成網址（`hokkaido-2028.html`），開了就不改。建議「地點-年份」。
- **標題**：網頁最上面的大標，之後要改請 TED 改。
- 開好會自動：建資料檔、產生網頁、加進首頁清單、推上 GitHub、綁到這個群。網頁約一分鐘後上線。
- 一個群可以綁好幾份（最多 5 份）：加綁用 `/小帥 行程 <名稱>`，看全部用 `/小帥 行程`，取消用 `/小帥 行程 取消 <名稱>`。綁了好幾份時，講到年份、日期或地點，小帥就知道是哪一份；沒線索時用剛剛在講的那份，再不然用最快出發的那份。

## 二、留言（群組任何人）

小帥不改行程，只幫大家把留言寫到網頁那天底下：

| 要做的事 | 怎麼說（例） |
|---|---|
| 留言 | 小帥 12/26 留言：神樂雪具記得帶手套（也可以說 D3、第 3 天） |
| 刪留言 | 小帥 刪掉 12/26 留言 2（第幾則看網頁上留言前面的編號） |
| 看用法 | 小帥 留言 |
| 看圖 | 小帥 給我看 D4、小帥 住宿傳圖給我 |
| 改行程 | 請 TED 改（小帥會回同一句話） |

規則（程式擋，不經 AI）：

- 留言直接寫入，不用回「好」；成功會回一句話＋網址，網頁約一分鐘後更新。
- 每則 100 字、每天最多 20 則（滿了要先刪舊的）；每群 10 分鐘最多 10 則。
- 網頁上顯示留言者的 LINE 名稱與時間；群組任何人都能刪任何一則，小帥會回覆刪了誰的哪一句。
- 寫進網頁的字一律跳脫，塞不進 HTML；網址顯示成純文字、不會變連結。
- 綁了好幾份行程時，用日期講（12/26、1/30）最不會弄錯；沒線索時小帥會反問是哪一份。

## 三、兩種版面

| | 通用版面 | 手刻版面 |
|---|---|---|
| 判斷 | 沒有 `trips/<名稱>.template.html` | 有自己的模板 |
| 頁首、住宿、連結 | 在資料檔（JSON） | 寫死在模板 |
| 例子 | snow-trip-2027 | christmas-ski-trip |

新行程一律用通用版面。要做特別的視覺（像聖誕那頁的住宿卡片）才另外手刻模板。

## 四、手動改（TED 在電腦上）

```bash
# 1. 改資料：trips/<名稱>.json（不要直接改 <名稱>.html，小帥會發現不同步而拒絕寫留言）
# 2. 重新產生網頁
node tools/trip.mjs build <名稱>
# 3. 確認網頁跟資料同步、測試通過
node tools/trip.mjs check <名稱>
node tools/trip.test.mjs
# 4. 只 add 這份行程的檔案再 commit、push
git add trips/<名稱>.json <名稱>.html
```

其他指令：`outline <名稱>`（精簡文字版，含留言）、`describe <名稱> <ops.json>`（試改不寫檔）、`apply <名稱> <ops.json>`（用 ops 改並重產網頁）、`create <名稱> <標題>`（等同群組的開新行程，但不會 commit）。

小帥隨時可能推留言進來：動手前先 `git pull`，改完盡快 push；撞到時以遠端的 JSON 為準重新 build，不要手動合併 HTML。

## 五、注意

- Mac 上的 clone 在 `~/apps/temp-reports`，小帥每次寫留言之前會 pull；那份 clone 有未提交的改動時，小帥會暫停寫入。
- 留言也是公開的，而且刪掉後在 git 歷史裡還查得到：不要留個資。小帥截某一天時會連留言一起截。
- 留言資料在 `days[].comments`（`by`、`at`、`text`），網頁由 `renderComments()` 產生；兩個模板的 `CMT-BEGIN`～`CMT-END` 與 `cmt-hint` 那行要一起改（測試會比對）。
- 行程結束後可以 `/小帥 行程 取消` 解除綁定；網頁留著當紀念，不用刪。
- 網頁是公開的：不要放護照號碼、電話、訂位代號這類個資。
- 每一項行程依文字自動上色、加標籤（交通／滑雪／用餐／活動／手續，規則在 `tools/trip.mjs` 的 `kindOf()`）。判錯時在 `trips/<名稱>.json` 該項加 `"type": "move|ski|food|sight|prep"` 再 build；改了該項標題或內容，手動的 `type` 會自動拿掉。兩個模板的 `KIND-BEGIN`～`KIND-END` 要一起改（測試會比對）。
- 每日行程是日期切換（一次顯示一天，另有「全部」籤）；網址帶 `#d3` 直接開那天，沒帶的話旅行期間開當天、其餘開 D1。沒有 JS、列印、小帥截圖（自動化瀏覽器，`navigator.webdriver` 為 true）時維持全部直排，改分頁 script 時不能拿掉這個判斷。兩個模板的 `TABS-BEGIN`～`TABS-END` 區塊要一起改（測試會比對）；本機用 Playwright 看分頁要在網址加 `?tabs=1`。
